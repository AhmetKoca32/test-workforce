## Öne Çıkan Özellikler

| Özellik | Açıklama |
|---|---|
| **Tek dosya** | CSS `<style>` içinde — harici bağımlılık yok |
| **Responsive** | `clamp()` + `grid auto-fit` + media query |
| **Sticky header** | `backdrop-filter: blur` ile modern cam efekti |
| **Gradient vurgular** | Başlık ve CTA kutusunda |
| **Hover efektleri** | Buton ve kart animasyonları |
| **Anlamsal HTML** | `header`, `section`, `footer` etiketleri |
| **Sıfır JS** | ~8KB, hızlı yüklenir |

## Nasıl Kullanılır

1. Kodu `index.html` olarak kaydedin
2. Tarayıcıda çift tıklayarak açın
3. Metinleri, renkleri (`:root` değişkenlerinden) ve linkleri kendinize göre düzenleyin

**Renk paletini hızlıca değiştirmek için** `:root` içindeki `--primary` ve `--primary-dark` değerlerini güncellemeniz yeterli. İsterseniz dark mode, iletişim formu veya SVG ikon desteği de ekleyebilirim.
